# Multi-Agent Workflow with LangGraph

A multi-agent AI workflow built with LangGraph and Google Gemini, where specialised agents collaborate sequentially to process a user's question and generate a final response.

## Project Overview

This project demonstrates how a task can be divided between multiple specialised AI agents instead of relying on a single agent to handle the complete process.

The workflow contains three specialised agents:

1. Researcher Agent
2. Reviewer Agent
3. Final Answer Agent

Each agent has a specific responsibility and passes its output to the next agent through the LangGraph state.

## Workflow Architecture

```text
User Question
      |
      v
Researcher Agent
      |
      v
Reviewer Agent
      |
      v
Final Answer Agent
      |
      v
Final Response
```

## How the Workflow Works

### 1. Researcher Agent

The Researcher Agent receives the user's question and generates relevant information based on the question.

Its main responsibility is to produce the initial research output.

### 2. Reviewer Agent

The Reviewer Agent receives the research produced by the Researcher Agent.

It reviews the information for relevance, clarity, missing points, and unnecessary information, then produces an improved version.

### 3. Final Answer Agent

The Final Answer Agent receives the reviewed research and uses it to generate a clear and concise final response to the user's original question.

## State Management

The workflow uses a shared LangGraph state to pass information between agents.

The state contains:

* `question` — the user's original question
* `research` — output generated by the Researcher Agent
* `review` — improved research generated by the Reviewer Agent
* `final_answer` — final response generated by the Final Answer Agent

## Installation

Clone or download the repository and open the project folder in VS Code.

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Environment Setup

Create a `.env` file in the project directory.

Add your Google Gemini API key:

```env
GOOGLE_API_KEY=your_api_key_here
```

Do not share your API key or upload the `.env` file to GitHub.

## Running the Project

Run the following command from the project directory:

```bash
python main.py
```

The program will ask for a question:

```text
Enter your question:
```

Enter a question and press Enter.

Example:

```text
What are the benefits of artificial intelligence?
```

The question will then pass through the Researcher Agent, Reviewer Agent, and Final Answer Agent before the final response is displayed.
